MeDIAuto WSI Anonymization - Windows x64 / 내부 연구용

설치 파일 하나에 프로그램, Philips 전용 런타임과 사용자 가이드 PDF가 포함됩니다.
Python, Conda 또는 SDK를 별도로 설치할 필요가 없습니다. 설치 시 다운로드하지 않습니다.

1. 설치 위치를 확인하고 Philips Research SDK 사용 조건을 확인합니다.
2. 필요하면 바탕화면 바로가기 생성을 선택합니다.
3. 설치가 끝나면 시작 메뉴의 MeDIAuto WSI를 실행합니다.
4. 시작 메뉴의 사용자 가이드에서 실제 화면과 사용 순서를 확인합니다.

설치는 현재 사용자 계정에 적용됩니다. 기본 설치 위치는
%LOCALAPPDATA%\Programs\MeDIAuto WSI 입니다.
프로그램과 동봉 philips 폴더는 같은 위치에 유지해야 합니다.
설치된 앱 목록 또는 시작 메뉴의 제거 항목으로 삭제할 수 있습니다.
별도 출력 폴더에 생성한 슬라이드와 CSV는 제거 프로그램이 삭제하지 않습니다.

원본 형식 유지는 파일 전체 복사가 아닙니다. 개인정보 메타데이터를 제외한 컨테이너를
새로 만들고 조직 압축 데이터를 복사한 뒤 무결성과 읽기 호환성을 검증합니다.
SVS는 전체 JPEG 타일 디코딩, NDPI와 Philips는 전체 압축 데이터 검증 및
일부 영상 영역 비교를 수행하므로 일반 파일 복사보다 시간이 걸릴 수 있습니다.
영상 검토 확인 체크박스는 사용자의 확인 기록이며 OCR 검사를 실행하지 않습니다.

현재 ICC는 기본 보존이며 내부 정보는 별도 검토 대상입니다.
조직 영상 속 개인정보는 직접 검토해야 합니다.
현재 설치본은 코드서명되지 않았습니다. 기관의 프로그램 설치 정책에 따라 사용하세요.
