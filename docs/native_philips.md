# Philips 원본 압축 유지 · 1.10.1

Philips `.i2syntax` / `.isyntax`를 **새 `.isyntax` 파일**로 저장합니다. 원본의 조직 압축 블록을 그대로 옮기므로 재압축이나 추가 압축 손실이 없습니다. TIFF가 아니며 일반 OpenSlide로는 열 수 없습니다. 이 프로그램 또는 해당 iSyntax 버전을 지원하는 Philips 도구를 사용하세요.

## 간단한 사용법

1. 파일을 추가하고 **1. 원본 형식 유지**를 선택합니다.
2. 파일명 변경과 CSV 포함 여부, 저장 위치를 확인합니다.
3. **선택 항목 내보내기**를 누릅니다.

같은 작업의 Philips는 `.isyntax`, 호환 SVS/NDPI는 `.svs`/`.ndpi`로 저장됩니다. 결과와 CSV는 날짜·시간 폴더에 모입니다. Philips에 TIFF가 필요하면 **3. TIFF 변환 · 무손실 압축**을 선택하세요. 출력 구조·실제 크기 정보·색상 프로파일은 **세부 설정**에서 확인할 수 있습니다.

## 함수 사용

```python
from wsi_anonymizer import anonymize_wsi

result = anonymize_wsi(
    "slide.i2syntax", "output",
    compression="philips",
    include_filename=False,
    preserve_icc=True,  # 기본값: 원본 색상 프로파일 유지
)
print(result["output_path"])  # anonymous_....isyntax
```

다른 프로젝트에서는 `wsi_anonymizer.py`와 릴리즈의 `philips` 폴더를 함께 사용합니다. 기존 API 기본값 `compression="preserve"`는 호환 JPEG TIFF/NDPI용으로 유지됩니다. GUI의 원본 유지는 `compression="native"`를 사용하며 Philips 전용 `philips`도 계속 지원합니다.

## 보존 및 제외 범위

- **보존:** 조직 압축 블록, 고유 압축 방식, 웨이블릿 양자화 설정, 원본 조직 해상도 단계와 실제 크기 보정 정보.
- **제외:** 원본 XML 텍스트, 라벨·매크로, 환자/검체 식별 항목, 스캐너 일련번호·스캔 일시. 새 SDK 파일에서 허용한 기술 XML 항목 외의 필드가 발견되면 내보내기를 실패 처리합니다.
- 조직 영상에 직접 찍힌 식별자는 자동 제거하지 않습니다. 원본 압축 유지에서는 마스킹·해상도 변경을 허용하지 않습니다. `redactions=()`, `pyramid=True`, `preserve_mpp=True`가 필요합니다.
- 색상 프로파일(ICC)은 기본 유지입니다. 제외하면 압축된 조직 데이터가 같아도 SDK가 표시하는 색상은 달라질 수 있습니다. 프로파일 내부 설명까지 보존되므로 기존과 같이 별도 검토 필요 상태로 기록합니다.
- 전체 압축 블록의 좌표·길이·바이트를 대조하고 SHA-256을 계산합니다. 모든 해상도 단계에서 일부 영역을 읽습니다. **전체 영상 픽셀을 모두 디코딩한 검증은 아닙니다.** ICC 포함 시에는 표본 영역의 표시 픽셀도 원본과 비교합니다.
- 검증과 원본 파일 변경 여부 확인 후에만 최종 파일을 게시합니다. 기존 파일은 덮어쓰지 않으며 취소·오류 시 임시 결과를 정리합니다.

현재 검증한 배치는 3개 색 성분, `legall53` / `RGB2YCoCg`, 9비트 내부 표본, 128×128 블록, 지원되는 `hulsken` 계열/Q 프리셋입니다. 다른 배치는 자동 재압축하지 않고 거부합니다. 두 제공 샘플은 `hulsken2`, `Q2`입니다.

## 실제 샘플 검증

| 샘플 | 원본 | 결과 (ICC 포함) | 압축 블록 | 개발 환경 실행 시간 |
|---|---:|---:|---:|---:|
| 첫 번째 | 105,055,621 B | 105,055,028 B | 46,164 | 약 1.7초 |
| 두 번째 | 211,555,284 B | 211,554,691 B | 107,433 | 약 3.5초 |

복사와 전체 압축 블록 비교, 새 XML 검증 및 영역 읽기를 포함한 측정입니다. PC·디스크·캐시 상태에 따라 달라지며 GUI/EXE 시작 시간은 별도입니다. ICC 제외 결과는 각각 105,032,183 B / 211,531,846 B였습니다.

SDK의 새 컨테이너 생성 기능을 사용하며 원본 파일을 수정하지 않습니다. SDK와 Python 3.7 런타임은 이전과 같이 내부 연구용 릴리즈에 동봉됩니다.
