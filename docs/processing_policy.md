# 원본 압축 유지 피라미드 TIFF + CSV 정책 v6

기술 정보 허용 목록: 원본 대물렌즈 배율, 전체 영상 픽셀 수, X/Y MPP, MPP로 계산한 전체 영상 영역 크기(mm). 기본 페이지 ImageDescription에는 이 숫자와 고정 스키마 식별자만 새로 작성하며 원본 설명문을 복사하지 않습니다. 출력 설명문은 생성한 내용과 정확히 일치하는지 검증합니다. 축소 페이지는 문자열 태그를 허용하지 않습니다. 원본에 없는 배율·MPP는 추정하지 않습니다. MPP 저장을 해제하면 TIFF의 MPP·Physical Size는 null입니다. CSV는 원본 기술 정보를 유지합니다.

`anonymize_wsi()`의 기본값은 `compression="preserve", pyramid=True`입니다. 첫 IFD는 최대 해상도 타일 영상이며 이후 IFD는 tiled/reduced-resolution 비트를 설정합니다. SubIFD는 사용하지 않습니다. `pyramid=False`로 최대 해상도만 저장할 수 있습니다.

최대 해상도 및 호환되는 원본 조직 축소 레벨의 JPEG 압축 데이터·코딩 테이블을 유지합니다. NDPI의 JPEG 높이·restart 번호만 조정하며 이 원본 레벨들은 재압축하지 않습니다. 추가로 필요한 작은 레벨은 검증된 출력에서 4배씩 줄여 긴 변이 512 이하가 될 때까지 생성합니다. JPEG 품질은 90입니다. 전체 영상을 메모리에 올리지 않고 경계 여유 픽셀을 포함한 작은 영역씩 처리합니다.

OpenSlide가 인식한 조직 레벨의 크기와 일치하는 호환 타일 페이지만 재사용합니다. 원본 label/macro/thumbnail IFD는 복사하지 않습니다. 지원하지 않는 최대 해상도 구조는 자동 재압축하지 않고 오류를 반환합니다. 현재 NDPI 압축 유지 경로는 1×1 샘플링, 완전한 restart 행과 호환 크기를 요구합니다.

원본 개인정보 태그·문자열·ICC·JPEG APP/COM·미참조 파일 영역을 제외합니다. 모든 출력 IFD에 구조 태그 허용 목록을 적용합니다. 픽셀에 직접 적힌 식별자와 원본 타일 패딩은 자동 제거하지 않습니다. `pixels_reviewed`는 호출자의 확인이며 자동 익명화 인증이 아닙니다. ICC 제외로 색상 관리 표시가 달라질 수 있습니다.

마스킹은 명시적 `compression="lossless"`에서 지원합니다. 원본 축소 레벨을 재사용하지 않고 마스킹된 최대 해상도 출력에서 피라미드를 생성합니다. 저장 압축은 Deflate이며 파일 크기가 늘 수 있습니다. 모든 채널·초점면 보존은 지원하지 않습니다.

원본 압축 유지 모드는 모든 출력 압축 타일의 SHA-256과 전체 디코딩을 검증합니다. 최대 해상도는 원본/출력의 25개 영역 픽셀도 비교합니다. Deflate 모드는 최대 해상도 RGB 픽셀 해시와 추가 레벨의 압축 무결성·디코딩을 검증합니다. 레벨 수·크기·타일 구조·태그 허용 목록·OpenSlide 재열기와 get_thumbnail을 확인한 뒤 게시합니다. 실제 샘플 테스트는 원본 전체 SHA-256도 비교합니다.

TIFF/CSV 중 하나 이상을 선택해야 합니다. CSV 전용 모드는 기술 정보만 읽고 영상 변환·픽셀 검증을 하지 않습니다. CSV 원본 파일명 포함을 해제하면 해당 열은 빈칸이며, 포함하면 파일명 자체의 개인정보도 남습니다. 기술 정보는 CSV_FIELDS 허용 목록만 사용하고 환자/검체 태그·스캔 날짜·일련번호·임의 설명을 추출하지 않습니다.

로컬 날짜·시간 폴더에 저장하며 같은 run_id의 순차 호출은 폴더/CSV를 공유합니다. CSV는 잠금하에 임시 파일로 기록합니다. Excel이 기존 파일 교체를 막으면 전체 목록의 새 시각 스냅샷을 저장하고 최신 경로를 반환합니다. 이후 호출은 최신 전체 목록을 이어서 기록합니다. CSV까지 저장하지 못하면 해당 호출의 새 TIFF를 정리합니다. 기존 결과는 덮어쓰지 않으며 취소·실패 시 임시 TIFF를 정리합니다. 강제 종료 시 임시 작업 파일이 남을 수 있습니다.

표준 TIFF로의 NDPI 재배치에는 반복 헤더가 추가되므로 결과가 항상 원본보다 작지는 않습니다. [실제 검증 기록](pyramid_tiff_validation.md)을 참조하세요.
