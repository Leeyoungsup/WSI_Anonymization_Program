# 원본 압축 유지 단일 TIFF + CSV 정책 v4

현재 내보내기는 `wsi_anonymizer.py`의 `anonymize_wsi()`를 사용합니다. 최대 해상도 level 0만 저장하고 출력 TIFF에는 IFD 1개, SubIFD 0개만 허용합니다. 이전 피라미드 결과와 검증 기록은 현재 출력 규격과 구분합니다.

기본 `compression="preserve"`는 JPEG 영상의 압축 데이터와 코딩 테이블을 유지합니다. SVS/TIFF의 독립된 baseline YCbCr JPEG 타일을 옮기고, NDPI의 독립된 restart 구간을 TIFF 규격에 맞게 묶습니다. NDPI의 JPEG 영상 높이와 restart 번호만 조정하며 인코더는 호출하지 않습니다. 현재 NDPI는 1×1 색상 샘플링과 완전한 restart 행, 호환되는 영상 크기를 요구합니다. 외부 JPEG 테이블을 사용하는 TIFF나 지원하지 않는 압축·구조는 명확한 오류로 중단하며 자동 재압축하지 않습니다.

JPEG APP/COM 메타데이터, 원본 TIFF 문자열·전용 태그·ICC·부속 이미지·미참조 파일 영역을 제외합니다. TIFF에는 허용된 구조 태그와 선택적 숫자 MPP만 기록합니다. JPEG 코딩 헤더는 허용 목록으로 검사하고 알 수 없는 마커는 거부합니다. 원본 영상 픽셀과 타일 패딩은 그대로 남으므로 픽셀 마스킹을 압축 유지 모드와 함께 요청하면 거부합니다.

다른 OpenSlide 지원 형식이나 마스킹은 `compression="lossless"`로 명시적으로 요청할 수 있습니다. 이 경로는 디코딩한 RGB를 Deflate로 저장하며 투명 픽셀·타일 바깥 패딩·좌표 마스크를 흰색으로 채웁니다. 원본보다 파일이 크게 늘어날 수 있습니다. `tile_size`와 `workers`는 이 경로에서만 저장 방식을 제어합니다.

원본 파일명을 포함한 대응 정보는 사용자 요청에 따라 **별도 CSV**에 기록합니다. 기술 정보는 코드의 `CSV_FIELDS` 허용 목록에 한정합니다. 알 수 없는 값은 공란이며, 환자/검체 식별 태그·스캔 날짜·스캐너 일련번호·임의의 설명 필드는 읽어 CSV로 옮기지 않습니다. 원본 파일명 자체의 개인정보는 자동 제거하지 않습니다.

출력 폴더는 로컬 실행 시각으로 생성합니다. GUI 일괄 작업의 성공 파일들은 같은 폴더와 CSV를 공유합니다. 공개 함수는 `run_id`를 생략하면 새 폴더를 만들고, 같은 날짜·시간 `run_id`를 지정해 순차 호출하면 한 폴더에 모읍니다.

기본 모드는 모든 출력 압축 타일을 기록 당시 SHA-256과 비교하고 모든 타일을 디코딩합니다. 이 검증은 압축 데이터 무결성과 전체 타일 읽기를 확인합니다. OpenSlide로 원본과 출력의 모서리·중앙을 포함한 25개 영역 픽셀도 비교합니다. 전체 원본 픽셀을 다시 디코딩해 비교하는 검증으로 표시하지 않습니다. 명시적 lossless 경로는 모든 출력 타일을 기록 당시 RGB 픽셀 해시와 비교합니다. 두 경로 모두 출력 영상 수, SubIFD 부재, 구조 태그 허용 목록, ASCII 태그 부재 및 OpenSlide 재열기를 검사합니다. 입력 주파일의 크기·수정시간을 비교하며 실제 샘플 테스트에서는 원본 전체 SHA-256도 비교합니다.

검증된 TIFF는 기존 파일을 덮어쓰지 않는 방식으로 게시합니다. CSV는 잠금하에 임시 파일을 기록하고 교체합니다. CSV 저장 실패 시 현재 호출이 만든 TIFF를 정리하고 실패를 반환합니다. 다른 성공 파일과 CSV 행은 보존합니다. 파일 시스템 전체를 아우르는 트랜잭션은 아니므로 강제 종료 시 임시 파일이나 CSV에 아직 기록되지 않은 TIFF가 남을 수 있습니다.

Excel이 기존 CSV의 교체를 막으면 `metadata_<저장 시각>.csv`에 전체 목록을 원자적으로 저장합니다. 이 경우 TIFF 변환은 정상 완료되며 실제 CSV 경로를 반환합니다. 이후 기록 시 이전 스냅샷도 병합해 행 손실을 방지합니다. 프로그램 내부 CSV 쓰기 잠금 충돌이나 스냅샷 저장까지 실패한 경우에만 실패를 반환합니다.

TIFF의 `metadata_clean`과 영상 속 개인정보 부재는 서로 다른 조건입니다. `pixels_reviewed`는 호출자의 검토 확인입니다. 자동 OCR 및 완전 익명화 인증은 제공하지 않습니다. ICC가 제외되므로 색상 관리 뷰어에서 표시가 달라질 수 있습니다.

모든 채널·초점면 보존은 지원하지 않습니다. OpenSlide 4.0.1 이상과 단일 영상 BigTIFF를 사용합니다. NDPI에는 JPEG 헤더가 추가되므로 원본 압축을 유지해도 결과가 반드시 원본보다 작지는 않습니다. 실제 두 샘플의 결과는 [검증 기록](preserved_tiff_validation.md)을 참조하세요.
