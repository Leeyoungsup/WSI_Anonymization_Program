# 단일 영상 TIFF + CSV 정책 v3

현재 내보내기는 `wsi_anonymizer.py`의 `anonymize_wsi()`를 사용합니다. 최대 해상도 level 0만 저장하고 출력 TIFF에는 IFD 1개, SubIFD 0개만 허용합니다. 이전 피라미드 결과와 검증 기록은 현재 출력 규격과 구분합니다.

TIFF에는 디코딩한 RGB 픽셀·영상 크기·선택적 숫자 MPP만 전달합니다. 원본 문자열, 전용 태그, ICC, 부속 이미지, 원본 JPEG 바이트, 미참조 영역은 복사하지 않습니다. 투명 픽셀과 타일 바깥 패딩은 흰색으로 채웁니다. 좌표 마스크는 level 0의 지정 영역을 흰색으로 덮습니다.

원본 파일명을 포함한 대응 정보는 사용자 요청에 따라 **별도 CSV**에 기록합니다. 기술 정보는 코드의 `CSV_FIELDS` 허용 목록에 한정합니다. 알 수 없는 값은 공란이며, 환자/검체 식별 태그·스캔 날짜·스캐너 일련번호·임의의 설명 필드는 읽어 CSV로 옮기지 않습니다. 원본 파일명 자체의 개인정보는 자동 제거하지 않습니다.

출력 폴더는 로컬 실행 시각으로 생성합니다. GUI 일괄 작업의 성공 파일들은 같은 폴더와 CSV를 공유합니다. 공개 함수는 `run_id`를 생략하면 새 폴더를 만들고, 같은 날짜·시간 `run_id`를 지정해 순차 호출하면 한 폴더에 모읍니다.

모든 출력 타일을 디코딩하고 기록 당시 픽셀 해시와 비교합니다. 출력 영상 수, SubIFD 부재, 구조 태그 허용 목록, ASCII 태그 부재 및 OpenSlide 재열기를 검사합니다. 입력 주파일의 크기·수정시간을 비교하며 실제 샘플 테스트에서는 원본 전체 SHA-256도 비교합니다.

검증된 TIFF는 기존 파일을 덮어쓰지 않는 방식으로 게시합니다. CSV는 잠금하에 임시 파일을 기록하고 교체합니다. CSV 저장 실패 시 현재 호출이 만든 TIFF를 정리하고 실패를 반환합니다. 다른 성공 파일과 CSV 행은 보존합니다. 파일 시스템 전체를 아우르는 트랜잭션은 아니므로 강제 종료 시 임시 파일이나 CSV에 아직 기록되지 않은 TIFF가 남을 수 있습니다.

TIFF의 `metadata_clean`과 영상 속 개인정보 부재는 서로 다른 조건입니다. `pixels_reviewed`는 호출자의 검토 확인입니다. 자동 OCR 및 완전 익명화 인증은 제공하지 않습니다. ICC가 제외되므로 색상 관리 뷰어에서 표시가 달라질 수 있습니다.

OpenSlide가 지원하는 2D RGB 표현을 처리하며 모든 채널·초점면 보존은 지원하지 않습니다. OpenSlide 4.0.1 이상과 타일 기반 무손실 Deflate BigTIFF를 사용합니다.
